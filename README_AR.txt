معرض الفن الافتراضي — النسخة الكاملة

المحتوى:
- Lobby ثلاثي الأبعاد بتصميم متحف حديث.
- 7 مداخل مستقلة للفصول.
- لكل فصل جناح فيه 4 قاعات:
  1) قاعة الرسم
  2) قاعة الزخرفة
  3) قاعة الطباعة
  4) قاعة الخزف
- كل قاعة فيها 20 مكانًا للصور.
- الإجمالي الممكن: 560 صورة.
- عند الضغط على الصورة تظهر بطاقة معلومات.
- يعمل على الكمبيوتر والجوال من المتصفح.

طريقة إضافة صور الأعمال:
داخل assets/artworks ستجدين:
class-1 ... class-7

داخل كل فصل:
drawing
decoration
printing
ceramics

ضعي صور كل قاعة في مجلدها وسمّيها:
01.jpg
02.jpg
...
20.jpg

ويمكن أن تكون الامتدادات:
.jpg أو .jpeg أو .png أو .webp

إذا لم تضعي صورة في خانة معينة، سيظهر Placeholder بدلها.

رفع النسخة على GitHub:
1) افتحي Repository: school-art-gallery
2) Add file > Upload files
3) ارفعي محتويات هذا المجلد كاملًا، وليس ZIP.
4) وافقي على استبدال index.html و gallery.html و data.js عند وجود نفس الاسم.
5) ارفعي أيضًا wing.html و styles.css ومجلد assets كاملًا.
6) Commit changes.
7) GitHub Pages سيعيد نشر الموقع تلقائيًا بعد دقائق.

مهم:
- لا تحتاجين data_structure.json لتشغيل هذه النسخة.
- يمكن إبقاؤه أو حذفه؛ لن يؤثر.
- الملف الأساسي لبدء الموقع هو index.html.
